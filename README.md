# Jagoan Math

Aplikasi kuis matematika interaktif untuk anak-anak. Belajar matematika jadi seru dengan tantangan, level, dan skor!

## Fitur

- **4 Kategori Soal** — Penjumlahan, Pengurangan, Perkalian, Pembagian
- **Multi Level** — Dari mudah sampai super sulit
- **Skor & Progress** — Kumpulkan skor tertinggi di setiap level
- **Responsive** — Bisa dimainkan di HP, tablet, dan desktop

## Tech Stack

- HTML5
- Bootstrap 5.3
- Vanilla JavaScript
- Google Fonts (Quicksand, Lexend)
- Material Symbols

## Cara Menjalankan

1. Clone repository
   ```bash
   git clone https://github.com/username/JagoanMath.git
   ```
2. Buka `index.html` di browser, atau jalankan dengan Live Server

## Struktur Folder

```
JagoanMath/
├── index.html          # Landing page

├── level.html          # Halaman pilih level
├── quiz.html           # Halaman kuis
├── result.html         # Halaman hasil
├── css/
│   └── bootstrap-custom.css  # Custom styling
├── js/
│   ├── app.js          # Logic landing page
│   └── quiz.js         # Logic kuis
└── data/
    └── soal.json       # Bank soal
```
